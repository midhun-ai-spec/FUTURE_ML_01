# Sales & Demand Forecasting for Businesses

## Objective
Build a machine learning model to forecast future sales using historical business data and generate business-friendly visual insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Features
- Data cleaning and preprocessing
- Time-based feature engineering
- Sales forecasting using Linear Regression
- Model evaluation using Mean Absolute Error (MAE)
- Future sales prediction
- Visualization of actual and predicted sales trends

## Dataset
Superstore Sales Dataset

## Methodology
1. Loaded and cleaned historical sales data.
2. Converted order dates into numerical time-based features.
3. Trained a Linear Regression model.
4. Predicted future sales for upcoming days.
5. Evaluated model performance.
6. Visualized results using graphs.

## Results
Successfully forecasted future sales trends and generated visual insights that can support business planning and decision-making.
