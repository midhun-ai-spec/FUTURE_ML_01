# Sales & Demand Forecasting for Businesses

## Objective
Built a machine learning model to forecast future sales using historical business data.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Jupiter Notebook
- VS Code

## Features
- Data cleaning
- Time-series forecasting
- Sales prediction
- Visualization
- Error evaluation

## Outcome
Predicted future sales trends using regression techniques and visualized forecast outputs.
