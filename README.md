# Sales & Demand Forecasting for Businesses

## Objective
Built a machine learning model to forecast future sales using historical business data.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Features
- Data cleaning
- Time-series forecasting
- Sales prediction
- Visualization
- Error evaluation

## Outcome
Successfully predicted future sales trends and visualized forecast results.
